# Freedom Broker — Conversation Quality Analytics (CQA)

Команда: **bandwagon fallacy**  
Хакатон: **Freedom Broker CQA Hackathon**

Сервис автоматизированной оценки качества диалогов службы поддержки Freedom Broker (текстовые чаты и аудиозвонки) на русском, казахском и английском языках (RU / KZ / EN). 

Реализует полный цикл проверки: расчет 8 критериев базового чек-листа, пропорциональное перераспределение весов при статусе N/A, нелинейную синхронизацию аудиозаписи звонка с репликами транскрипта, контур подачи и рассмотрения апелляций супервизором, а также экспорт в утвержденный формат JSON.

---

## Быстрый запуск

### Требования
- Python 3.9 или выше.
- Для базовой работы внешние библиотеки не требуются (сервер работает на стандартной библиотеке Python: `http.server`, `sqlite3`, `urllib`, `json`).

### Запуск сервера
```bash
python server.py
```

После запуска откройте в браузере:
- Основной интерфейс CQA: http://localhost:8080
- Режим встраивания Microsoft Dynamics 365 Web Resource: http://localhost:8080/?d365=1

База данных SQLite (`data/cqa.db`) инициализируется автоматически при первом старте.

## Результаты оценки (формат хакатона)

В соответствии с регламентом хакатона файлы результатов располагаются в двух папках:
- `results/dev/results.json` — результаты оценки DEV-набора (60 чатов и 5 аудиозвонков).
- `results/prod/results.json` — результаты оценки контрольного набора PROD (10 контрольных чатов).

Оба файла строго соответствуют спецификации JSON 1.0 (8 критериев на диалог, валидные типы `true / false / null / scale`, 1-based нумерация реплик `evidence_turns`, округление `final_score` до 2 знаков, поле `team_name: "bandwagon fallacy"`).

### Выгрузка результатов

Экспорт можно выполнить двумя путями:
1. **Через веб-интерфейс:** в шапке нажать кнопку «Настройки» -> «Скачать results.json». Файл автоматически скачивается и обновляется в локальной папке репозитория `results/dev/results.json` (или `results/prod/results.json` в зависимости от выбранного набора).
2. **Через REST API:**
```bash
# Выгрузка DEV:
curl -o results/dev/results.json "http://localhost:8080/api/export/hackathon?group_id=DEV"

# Выгрузка PROD:
curl -o results/prod/results.json "http://localhost:8080/api/export/hackathon?group_id=PROD"
```

## Оценка контрольного набора PROD (на 23-м часу)

Когда организаторы предоставят доступ к контрольному набору:
1. Запустите сервер: `python server.py`.
2. В интерфейсе в верхнем переключателе выберите `PROD` (или введите выданный `group_id`) и нажмите «Загрузить сет». Либо передайте `ORGANIZER_API_URL` в переменной окружения:
   ```bash
   export ORGANIZER_API_URL="https://endpoint-organizatorov"
   python server.py
   ```
3. Нажмите «Оценить всё».
4. Нажмите «Настройки» -> «Скачать results.json». Сервер сформирует и запишет файл `results/prod/results.json`.
5. Отправьте изменения в Git:
   ```bash
   git add results/prod/results.json
   git commit -m "Add PROD evaluation results"
   git push origin main
   ```

## Режимы оценки

1. **Встроенный движок (по умолчанию):** работает полностью автономно и локально, не требует API-ключей и интернета. Реализует правила чек-листа Freedom Broker, перераспределение весов N/A, определение задержек SLA первого ответа и цитирование реплик-доказательств.
2. **Внешний LLM API (Google Gemini / OpenAI / Ollama):** включается при вводе API-ключа через меню «Настройки» -> «API ключ» или переменную окружения `GEMINI_API_KEY`. Модель по умолчанию: `gemini-flash-lite-latest` с автоматическим отказоустойчивым переключением цепочки моделей при лимитах квот.

## Основные компоненты системы

- `server.py` — HTTP/REST сервер, эндпоинты `/api/conversations`, `/api/evaluate`, `/api/export/hackathon`, `/api/audio/<id>`, SQLite хранилище.
- `evaluator.py` — движок расчета 8 критериев, алгоритм перераспределения весов N/A со страницы 2 регламента, нелинейное выравнивание временных меток аудио и транскрипта, клиент LLM API.
- `asr_pocketsphinx.py` — локальный модуль акустической обработки звонков и нормализации билингвальных транскриптов KZ/RU.
- `public/index.html` — пользовательский интерфейс в концепции Material You Expressive (лента диалогов с фильтрами, холст диалога с анимацией реплик, SVG-ползунок аудио с бегущей волной, модальные окна конструктора чек-листа и подачи апелляций).
- `results/` — директории для сдачи результатов (`results/dev/results.json` и `results/prod/results.json`).
